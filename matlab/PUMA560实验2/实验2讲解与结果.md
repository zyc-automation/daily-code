## 二、修正 D-H 法原理

### 2.1 坐标系建立规则（按题目 P7 的描述）

- 以关节 i-1 的轴线为 **z_{i-1} 轴**（正方向自选）；
- 以指向下一级连杆的方向为 **x_{i-1} 轴**；
- 用**右手定则**确定 y_{i-1} 轴；
- 对每个关节建立联体坐标系 {i}。

### 2.2 相邻坐标系变换矩阵（参数下标统一用 i）

修正 D-H 约定下，第 i 个变换（坐标系 {i} 相对 {i-1}）为：

```
T(i) = Rx(α_i) · Dx(a_i) · Rz(θ_i) · Dz(d_i)
```

展开成 4×4 矩阵：

```
        [  cosθ_i          -sinθ_i          0       a_i           ]
        [  sinθ_i·cosα_i    cosθ_i·cosα_i  -sinα_i  -d_i·sinα_i   ]
T =     [  sinθ_i·sinα_i    cosθ_i·sinα_i   cosα_i   d_i·cosα_i   ]
        [  0                0               0        1            ]
```

四个参数含义：

| 参数 | 含义 |
|------|------|
| a_i   | 连杆 i 的长度（沿 x_i 轴） |
| α_i   | 连杆 i 的扭角（绕 x_i 轴，从 z 轴转到下一关节 z 轴的角度） |
| d_i   | 关节 i 的偏置（沿 z_i 轴） |
| θ_i   | 关节 i 的转角（绕 z_i 轴，关节变量） |

> 注意：修正 D-H 与标准 D-H 的区别在于**变换顺序**——修正 D-H 是 `Rx·Dx·Rz·Dz`，
> 标准 D-H 是 `Rz·Dz·Dx·Rx`，两者矩阵元素排列完全不同，建模时务必按题目的修正 D-H 来。

## 四、正运动学

末端位姿 = 六个变换连乘：

```
T06 = T01 · T12 · T23 · T34 · T45 · T56
```

其中 T = [R | p]，R 为末端姿态（3×3 旋转矩阵），p 为末端位置（3×1 平移向量）。

代码里 `PUMA560_FK.m` 用循环连乘实现；`T(1:3,1:3)` 即姿态，`T(1:3,4)` 即位置。

## 五、逆运动学解析解（代数法推导）

本题 d6=0，末端位置 p 就是球腕中心位置。给定 T=[R|p]，记 px,py,pz。

### 5.1 求 θ1

由 {4} 原点在 {1} 中的 y 分量等于 d2，得到关键方程：

```
-px·sinθ1 + py·cosθ1 = d2
```

令 `r = sqrt(px² + py²)`，`φ = atan2(py, px)`，则：

```
sin(φ - θ1) = d2 / r
θ1 = atan2(py, px) - atan2(d2, ±sqrt(px²+py²-d2²))
```

± 号给出 θ1 的两个解（肩部左/右）。

### 5.2 求 θ3（消去 θ2）

令 `K = px·cosθ1 + py·sinθ1`，由位置分量平方和消去 θ2：

```
K² + pz² = a2² + a3² + d4² + 2·a2·a3·cosθ3 - 2·a2·d4·sinθ3
```

即 `a3·cosθ3 - d4·sinθ3 = k`，其中

```
k = (K² + pz² - a2² - a3² - d4²) / (2·a2)
```

化为 `r3·cos(θ3+ψ) = k`，`r3 = sqrt(a3²+d4²)`，`ψ = atan2(d4, a3)`，得：

```
θ3 = ±acos(k / r3) - atan2(d4, a3)
```

± 号给出 θ3 的两个解（肘部上/下）。

### 5.3 求 θ2

由线性方程组（X、Y 为含 θ3 的中间量）：

```
X = a2 + a3·cosθ3 - d4·sinθ3
Y = a3·sinθ3 + d4·cosθ3
θ2 = atan2(-X·pz - K·Y,  K·X - Y·pz)
```

### 5.4 求腕部 θ4、θ5、θ6

前三个关节的旋转矩阵 R03 可算得，于是：

```
R36 = R03ᵀ · R
```

腕部等价于 Z-Y-Z 欧拉角。设 R36 = (r_ij)，则：

```
θ5 = atan2(±sqrt(r13² + r33²),  r23)
θ4 = atan2(±r33,  ∓r13)   （± 与 θ5 同号）
θ6 = atan2(∓r22,  ±r21)
```

θ5 的正负号给出腕部"翻转/未翻转"两解。

综上：θ1 两解 × θ3 两解 × 腕部两解 = **最多 8 组解**。
