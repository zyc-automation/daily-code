# daily-code 🟩

张宇诚的每日编程学习打卡仓库。

> 每天写几行，点一下推送。让 GitHub 贡献图记录你的每一步。

---

## 目录结构

```
daily-code/
├── python/          # Python 学习日志（按月归档 .md）
├── c/               # C 语言 / 嵌入式学习日志（按月归档 .md）
├── matlab/          # MATLAB 学习日志 + 仿真代码
│   ├── 2026-08/     # 每日笔记（.md）
│   └── control-sim/ # 控制仿真代码（.m 文件，按章节分）
├── ros2/            # ROS2 学习日志（按月归档 .md）
├── projects/        # 项目笔记（倒立摆、小车等）
├── newday.bat       # 🆕 双击自动创建今天的笔记模板
├── startup.m        # 🆕 MATLAB 启动脚本
├── push.bat         # 双击自动提交 + 推送到 GitHub
└── README.md
```

---

## 每日操作（只需 3 步）

```
┌─────────────────────────────────────────────────┐
│                                                 │
│  ① 双击 newday.bat                              │
│     → 自动生成今天的 .md 笔记模板               │
│     → 自动打开 daily-code 文件夹                │
│                                                 │
│  ② 打开 MATLAB，写代码，保存到 control-sim/     │
│     在 .md 文件里写今天的笔记                    │
│                                                 │
│  ③ 双击 push.bat                                │
│     → 自动提交 + 推送到 GitHub ✅               │
│                                                 │
└─────────────────────────────────────────────────┘
```

### newday.bat 做了什么

- 自动检测今天日期和星期
- 为 `matlab/`, `ros2/`, `python/`, `c/` 四个目录分别创建当月文件夹和当天笔记模板
- **安全保护**：如果某天的笔记已经写了内容，不会覆盖
- 自动打开 daily-code 文件夹，直接开干

---

## MATLAB 配置（让代码自动保存在 daily-code 下）

**推荐方法**：修改 MATLAB 桌面快捷方式的「起始位置」

```
右键 MATLAB 图标 → 属性 → 起始位置 → 改为：
C:\Users\allen\daily-code
```

改完以后每次打开 MATLAB，默认工作路径就是 daily-code。Ctrl+S 保存 `.m` 文件，直接就在仓库里了。

## 记录格式

没有硬性要求，可以写：
- 今天跑通了什么代码
- 踩了什么坑、怎么解决的
- 一个知识点的一行总结
- 甚至"今天只看了一个概念，明天继续"

**关键不是写多好，是每天都写。**
