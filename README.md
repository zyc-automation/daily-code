# daily-code 🟩

张宇诚的每日编程学习打卡仓库。

> 每天写几行，点一下推送。让 GitHub 贡献图记录你的每一步。

---

## 目录结构

```
daily-code/
├── python/          # Python 学习日志（按月归档）
├── c/               # C 语言 / 嵌入式学习日志
├── matlab/          # MATLAB 学习日志 + 仿真代码
│   ├── 2026-08/     # 每日笔记（.md）
│   └── control-sim/ # 控制仿真代码（.m 文件）
├── ros2/            # ROS2 学习日志
├── projects/        # 项目笔记（倒立摆、小车等）
├── push.bat         # 双击自动提交+推送
└── README.md
```

## 每日操作（30 秒）

1. 打开 `python/` 或 `c/` 下的当月文件夹
2. 找到今天的文件（如 `09.md`），写几行今天学了什么
3. 双击根目录下的 `push.bat` → 自动推送到 GitHub ✅

## 记录格式

没有硬性要求，可以写：
- 今天跑通了什么代码
- 踩了什么坑、怎么解决的
- 一个知识点的一行总结
- 甚至"今天只看了一个概念，明天继续"

**关键不是写多好，是每天都写。**
