## 二、五个台阶

### 台阶 1:自由单摆(无控制)
- **文件**:`step1_simple_pendulum.py`
- **核心知识点**:欧拉积分 + 单摆动力学
- **物理**:摆杆绕固定轴,重力让它自然摆动。θ=0 是竖直向下(稳定)。
- **公式**:
  - 角加速度:`θ'' = -(g/L)·sin(θ)`(负号 = 重力把摆拉回下面)
  - 欧拉积分:`θ_dot += θ_ddot·dt`;`θ += θ_dot·dt`
- **现象**:角度随时间做正弦摆动(波浪线)。

### 台阶 2:倒立摆 + P 控制
- **文件**:`step2_inverted_pendulum_p.py`
- **核心知识点**:倒立摆(目标竖直向上,不稳定)+ 比例控制
- **关键区别**:θ=0 变成竖直向上,重力项的符号反了:`θ'' = (g/L)·sin(θ) + τ/I`
- **P 控制**:`τ = -Kp·θ`(摆杆往右歪,反向掰)
- **现象**:摆杆能立住,但一直来回振荡(没有刹车)。

### 台阶 3:倒立摆 + PD 控制
- **文件**:`step3_inverted_pendulum_pd.py`(填空)、`step3_animate.py`(动画)
- **核心知识点**:D 项(微分)提供"阻尼/刹车",消除振荡
- **PD 控制**:`τ = -Kp·θ - Kd·θ_dot`
  - P 项看"歪了多少"(角度)
  - D 项看"歪得多快"(角速度),倒得快就加反向力矩刹车
- **现象**:摆杆从 15° 平滑收敛到 0,不再振荡。
- **试玩**:`Kd=0` 退化回台阶 2;`Kd` 调大 = 刹车过头变慢。

### 台阶 4:小车 + 倒立摆 + PD 控制
- **文件**:`step4_cart_pole_pd.py`(填空)、`step4_animate.py`(动画)
- **核心知识点**:两个耦合方程联立求解(矩阵)+ 控制符号反转
- **状态(4 个)**:`[x, x_dot, θ, θ_dot]`(小车位置、小车速度、摆杆角度、摆杆角速度)
- **两个耦合方程**(忽略摩擦):
  - ① `(M+m)·x_ddot + m·l·cosθ·θ_ddot = F + m·l·sinθ·θ_dot²`
  - ② `m·l·cosθ·x_ddot + (I+m·l²)·θ_ddot = m·g·l·sinθ`
  - 写成矩阵 `A·[x_ddot, θ_ddot] = b_vec`,用 `np.linalg.solve(A, b_vec)` 解
- **⚠️ 控制符号反转**(最反直觉):
  - 台阶 3 力矩直接掰摆杆:`τ = -Kp·θ`
  - 台阶 4 力作用在小车上:`F = +Kp·θ + Kd·θ_dot`(符号相反!)
  - 直觉:筷子往右倒,手要往右追,不是往左
- **现象**:摆杆立住了,但小车一路匀速滑走(无摩擦 + PD 没管小车位置)。

### 台阶 5:小车 + 倒立摆 + LQR 最优控制
- **文件**:`step5_lqr.py`(填空)
- **核心知识点**:状态空间 + 线性化 + Riccati 方程 + 全状态反馈
- **LQR 三步**:
  1. 线性化(在 θ=0 附近,sinθ≈θ、cosθ≈1),写成 `dx/dt = A·x + B·u`
  2. 定义代价函数 `J = ∫(xᵀQx + uᵀRu)dt`:Q 惩罚状态偏离,R 惩罚用力
  3. 解 Riccati 方程得 P,算增益 `K = R⁻¹·Bᵀ·P`,控制律 `u = -K·x`
- **代码三步**:
  - `P = solve_continuous_are(A, B, Q, R)`
  - `K = np.linalg.inv(R) @ B.T @ P`
  - `u = -K @ state`
- **现象**:摆杆立住 + 小车回到原点(解决台阶 4 跑偏问题)。
- **算出的 K** = `[-3.16, -4.37, -39.85, -7.54]`(θ 权重最大,其次 x)

## 三、核心概念总结

1. **状态**:一组数完整描述系统"现在长什么样"。倒立摆 = 4 个数 `[x, x_dot, θ, θ_dot]`。
2. **欧拉积分**:`变化量 = 变化率 × 时间步长 dt`。所有仿真的根基。
3. **P → PD → LQR 的递进**:
   - P:能立住,但振荡(没有阻尼)
   - PD:能稳住(加了阻尼)
   - LQR:同时管住摆杆和小车,自动算出最优反馈(全状态反馈)
4. **控制符号取决于"作用点"**:力矩直接作用摆杆(负号)vs 力作用小车(正号)。
5. **线性化**:在平衡点附近用直线近似曲线,sinθ≈θ、cosθ≈1,让非线性系统变成可处理的线性系统。

## 四、踩过的坑(重点复习)

1. **欧拉积分漏乘 dt**:`θ_dot = θ_dot + θ_ddot`(错)→ `θ_dot = θ_dot + θ_ddot * dt`(对)。漏了 dt 等于把 0.001 秒当成 1 秒,系统爆炸。
2. **控制符号反了**:台阶 4 照抄台阶 3 的负号,摆杆倒得更快。作用点变了,符号要跟着变。
3. **无摩擦导致小车滑走**:台阶 4 简化掉了摩擦,所以 PD 扶正摆杆后小车匀速滑走不停。想让它停,加摩擦 `-b·x_dot` 或用 LQR 反馈 x。
