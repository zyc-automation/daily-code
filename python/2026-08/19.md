## 今天做了什么

- 倒立摆控制从 0 到 LQR,走了 5 个台阶(代码在 `projects/pendulum/`)
  - 台阶1 自由单摆:欧拉积分 + 单摆动力学 `θ'' = -(g/L)·sinθ`
  - 台阶2 倒立摆 + P 控制:能立住但一直振荡 `τ = -Kp·θ`
  - 台阶3 倒立摆 + PD 控制:D 项加阻尼,稳住不晃 `τ = -Kp·θ - Kd·θ_dot`(+ 动画)
  - 台阶4 小车+摆杆 + PD:矩阵联立求解 + 控制符号反转 `F = +Kp·θ + Kd·θ_dot`(+ 动画)
  - 台阶5 小车+摆杆 + LQR:状态空间 + Riccati 方程 + 全状态反馈 ✅ 已完成
- 结果:LQR 摆杆欠阻尼收敛到 0,小车先冲出去再被拉回原点

## 踩坑 / 收获

- 欧拉积分漏乘 dt:`变化量 = 变化率 × dt`,漏了 dt 等于把 0.001 秒当 1 秒,系统爆炸
- 控制符号反转:力矩直接掰摆杆(负号)vs 力作用小车(正号)——筷子往右倒,手往右追
- 无摩擦导致小车匀速滑走:PD 只反馈角度、管不住小车位置 → LQR 用全状态反馈解决
- PyCharm 报"找不到文件" = 路径 / 运行配置问题,不是代码问题
- 环境坑:机器原来没装 numpy/matplotlib/scipy,那个 888 行的倒立摆代码之前根本跑不起来
- 矩阵运算:`@` 是矩阵乘法,`*` 是逐元素乘法;`B.T` 是转置(维度匹配用)
